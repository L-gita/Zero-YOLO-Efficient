# 指标定义与算法说明（答辩用）

> 目的：答辩时被问"你这个色度噪声/条带/边缘指标是怎么算的、是不是随便给的"，本文档给出**每个指标的数学定义、实现位置、阈值与判读方向**。
> 所有指标都由 `C:\Users\12983\Documents\repro\scripts\` 下的脚本计算，可命令行复跑（见文末"复现方式"）。

## 0. 约定

- 所有图像统一转成 **uint8 sRGB**（0~255）再计算；浮点中间结果只在内部使用。
- 灰度：`Y = 0.299R + 0.587G + 0.114B`（OpenCV `COLOR_RGB2GRAY` 同一公式，BT.601）。
- 色度：`cv2.cvtColor(img, COLOR_RGB2YCrCb)` 得到 `Y, Cr, Cb`，两者围绕 128 波动。
- "暗区掩码"：`gray < 40`；若该掩码像素占比 < 2%，放宽为 `gray < 80`（极暗图专用，避免掩码为空）。

## 1. 平均亮度 `brightness`

**定义**：整幅图像灰度均值，单位 0~255。

```
brightness = mean(Y)
```

- 实现：`scripts/compare_preprocess.py` 与 `scripts/eval_default_vs_base.py: measure()` 内联；`scripts/mosaic_ablation.py` 亦有同口径。
- 判读：越大越亮。用于验证"增强是否过曝/是否偏暗"。

## 2. 色度噪声 `chroma_noise`（核心指标之一）

**定义**：Cb/Cr 的**高频残差**标准差（对噪声最敏感、对亮度变化不敏感）。

```
C_hi = C - GaussianBlur(C, σ=1.5)          # C 分别为 Cb / Cr
chroma_noise = ( std(Cb_hi) + std(Cr_hi) ) / 2      # 全图 std（ddof=0）
```

- 实现：`scripts/preprocess.py: estimate_chroma_noise()`（输入图口径）与 `chroma_noise()`（输出图口径，含暗区掩码版本）。
- 单位：0~255 灰度级（因为 YCrCb 的 Cb/Cr 与 Y 同尺度）。
- 判读：**越小越干净**。彩色噪点（红绿蓝斑点）主要计入此项。
- 为什么用高斯高通：噪声是高频、雾气/光照是低频，减掉 σ=1.5 的低频后，剩下的主要是噪声 + 真实细边缘；在**平坦区**统计时基本只剩噪声。

## 3. 平坦区亮度噪声 `luma_noise_flat`

**定义**：只在"平坦区"统计的高频残差标准差。

```
flat_mask = (|Sobel_x(Y)| + |Sobel_y(Y)|) < 20      # 输入图的梯度很弱处
luma_noise_flat = mean( |Y - GaussianBlur(Y, σ=1.5)| [flat_mask] )
```

- 实现：`scripts/eval_default_vs_base.py: _flat_mask() + _hf() + measure()`。
- 判读：越小越干净；限制在平坦区可避免把"真实纹理"算成噪声。

## 4. 细节强度 `detail_std8`

**定义**：8×8 块内灰度的局部标准差，再对全图取均值。

```
detail_std8 = mean over blocks( std( Y[8x8 block] ) )
```

- 实现：`scripts/eval_default_vs_base.py: measure()`（局部 std：`sqrt(E[Y²]-E[Y]²)`，8×8 窗）；`scripts/mosaic_ablation.py: luma_std8()`。
- 判读：**越高细节越多**。注意：它同时包含噪声，所以"压噪后必然下降"，**不能单独当纹理损失**，必须与"色度噪声/平坦区噪声"一起看。

## 5. 暗区条带 `band_jump` 与 `n_levels`

**定义**（只在暗区掩码内统计）：

```
levels = 灰度直方图中占比 > 1% 的灰度级
n_levels   = len(levels)                       # 暗区"大面积灰度级"个数，越多越细腻
band_jump  = max(相邻 levels 之间的间隔)         # 暗区"最大台阶"，越大越容易出现硬色阶
```

- 实现：`scripts/mosaic_ablation.py: band_jump() / n_levels()`；`scripts/eval_default_vs_base.py` 内联同公式。
- 判读：`band_jump` 越小越好（≤3 基本不可见；≥8 肉眼可见台阶）；`n_levels` 越大越好。
- 背景：8-bit 只有 256 级，暗部可能只用到 18~37 级，增强曲线放大 5~13 倍后，一级输入台阶就变成 5~13 级输出台阶 → 这就是"马赛克/条带"的量化解释。

## 6. 人造边界 `artificial_edges`

**定义**：每千像素中，"色度跳变大但亮度几乎不变"的像素数——这种边界在真实场景里不存在，是算法自己造出来的（色块分界线）。

```
ΔC(p) = |Cb(p) - Cb(p-1)| + |Cr(p) - Cr(p-1)|     # 水平/垂直取较大者
ΔY(p) = |Y(p)  - Y(p-1)|
artificial_edges = 1000 * count( ΔC ≥ 3 且 ΔY < 1 ) / 像素总数
```

- 实现：`scripts/preprocess_v4.py: artificial_edges()`。
- 判读：**越小越好**。它专门抓"色块拼接感"；纯 PSNR/SSIM 抓不到这种局部不自然。
- 局限：亮度噪声被压掉后，原先被掩盖的色度跳变会"显形"，数值会虚高 → 需配视觉图解读（已写入 README §8.4 的更正说明）。

## 7. 彩色块面积占比 `colored_plateau`

**定义**：把 Cb/Cr 量化到若干档后，统计"有色"（色度幅度 `|Cb-128|+|Cr-128| ≥ 8`）的同值连通域，取最大块的面积占比。

```
plateau% = 100 * max_area(同值连通域) / 总像素
```

- 实现：`scripts/mosaic_ablation.py: chroma_plateau()`。
- 判读：越小越好；>5% 通常能看出"大片同色斑块"。

## 8. 块效应比 `blockiness`（8×8 JPEG 块检测）

**定义**：JPEG 按 8×8 块做 DCT，块边界两侧会出现不连续。比较"8 的倍数行/列"与其它行/列的平均绝对差：

```
blockiness = mean_{边界行/列} |ΔY| / mean_{非边界行/列} |ΔY|
```

- 实现：`scripts/preprocess.py: estimate_blockiness()`；`scripts/mosaic_ablation.py: blockiness()`（**只在平坦区统计**，否则真实竖直边缘会让无损 PNG 也判成 1.2+）。
- 判读：≥1.03 认为存在块效应；PNG 正常值 ≈0.98~1.00，JPEG q95≈1.4，q70≈3.2，q40≈5+（实测标定见 README §8.6）。
- 局限：只能看 8×8 网格，**看不到 32 像素级的大色块**（这是早期误判的原因，已改为"块效应 + 彩色块面积"双指标）。

## 9. 噪声标准差估计 `estimate_noise`（Immerkær 法）

**定义**（Immerkær 1996 经典快速噪声估计）：

```
L = 3x3 Laplacian 卷积(img_gray)
σ_lap = median(|L|在暗区) / 0.6745       # MAD → 标准差
σ = σ_lap / sqrt(sum(laplacian_kernel^2))   # OpenCV ksize=3 时 sqrt(80)≈8.94
```

- 实现：`scripts/preprocess.py: estimate_noise()`。
- **实测校准**：合成已知 σ=1/2/5/10 的高斯噪声图 → 本函数返回 8.90/17.79/44.48/88.95，即当前实现返回的是"拉普拉斯域尺度"（未除 √80），约等于 **8.94×真实 σ**。
- 工程影响：阈值（如 `chroma_lo=1.5`、`chroma_hi=2.5`）都是按这个尺度标定的，内部自洽；**论文里若要写"σ=..."，需说明尺度或额外除以 √80**。

## 10. PSNR / SSIM（相对正常光 GT，仅 eval15 有）

**PSNR**：

```
MSE = mean((I_enh - I_gt)^2)            # 0~255 尺度
PSNR = 10 * log10(255^2 / MSE)          # dB
```

**SSIM**（Wang et al. 2004，11×11 高斯窗 σ=1.5，RGB 三通道均值）：

```
SSIM(x,y) = ((2μxμy + C1)(2σxy + C2)) / ((μx²+μy²+C1)(σx²+σy²+C2))
C1=(0.01*255)², C2=(0.03*255)²
```

- 实现：`scripts/eval_lol.py` / `scripts/compare_preprocess.py` / `scripts/eval_default_vs_base.py`（自实现，与 skimage 口径一致）。
- 判读：越大越好。注意 SSIM 对"平滑"有偏好，需与 `detail_std8`、`artificial_edges` 同看。

## 11. Canny 边缘精度 / 召回（下游友好度）

**定义**：以正常光 GT 的 Canny 边缘为"真值"，把增强图边缘做 3 像素容差匹配：

```
E_pred = Canny(gray(enh), 50, 120);  E_gt = Canny(gray(gt), 50, 120)
precision = |E_pred ∩ dilate(E_gt, 3px)| / |E_pred|
recall    = |E_gt ∩ dilate(E_pred, 3px)| / |E_gt|
```

- 实现：`scripts/eval_edges_vs_gt.py`。
- 判读：抓取任务更看重 **precision**（别把噪声当轮廓）；recall 略降可接受。
- 局限：这是"边缘是否落在 GT 轮廓附近"的代理指标，**不等于抓取成功率**（我们没有端到端实验，报告里不能这么写）。

## 12. 饱和度 / 梯度一致性

- `saturation = mean(S)`，S 为 HSV 的 S 通道（0~1）→ 判断"是否被洗淡"。
- `cos_struct`：两图梯度向量（Sobel gx,gy）的全局余弦相似度；`corr_mag`：梯度幅值图的相关系数 → 判断"结构有没有被破坏"。
- 实现：`scripts/pair_compare.py: sobel_fields()/cosine_grads()/corr_maps()`。

## 13. 判定阈值（当前算法内部使用）

| 判定 | 阈值 | 代码 |
|---|---|---|
| 近黑分支 | 整图均值 `m < 5` | `preprocess.py: auto_decision()` |
| 跳过（色度干净） | 输入色度噪声 `σc < 1.5` | 同上 |
| 色度平滑强度（分段） | `σc<0.3→0`；`0.3~0.6→0.35σc`；`0.6~1.0→0.5σc`；`≥1.0→min(0.7,0.7σc)` | `preprocess.py: chroma_light_strength()` |
| 去块触发 | `blockiness > 1.03` | `preprocess.py: auto_preprocess()` |
| 暗部补偿 | 输入均值 `< 15` 时抬 4 级 | `enhance.py: --shadow-lift=-1` |
| 近黑限增益 | 输入亮度 `<3` 全中性抬亮，`3~12` 线性羽化，`>12` 不动 | `preprocess.py: limit_dark_gain()` |
| 分区自适应（experimental） | 局部亮度 `P25~P55` 分位之间渐变 | `preprocess.py: region_adaptive()` |
