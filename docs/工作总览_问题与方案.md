# 工作总览：对图像做了什么、针对什么问题、怎么解决、效果如何

> 一句话概括：**我们在 Zero-DCE 之外加了一层"终端侧自适应预处理/后处理"，专门对付低照增强后出现的量化马赛克与色噪；同时用训练侧边缘损失保住结构。**
> 本文档按"问题 → 机理 → 我们的操作 → 证据"组织，可直接作为论文第 3~4 章的骨架。

## 第二部分 问题清单（现象 → 机理 → 证据）

### 问题 1：暗部马赛克 / 硬台阶（最主要）

- **现象**：极暗图增强后出现成片色块、台阶状边界，越暗越明显。
- **机理**：8-bit 图像暗部只用到很少的灰度档（实测 126_3_ 全图仅 **25 级**、147_0_ **18 级**）；DCE 曲线在暗区斜率 = 1+|α|，端到端增益实测 **10.7~12.7×**（≤1 级输入台阶 → 10~13 级输出跳变）→ 相邻两档变成十几级差 → 肉眼就是"块"。
- **证据**：`band_jump` 指标（暗区大面积灰度级最大间隔）：126 基线 12 级 → 处理后 3 级；`n_levels`（暗区级数）9→18。

### 问题 2：彩色噪点 / 色斑（color blotch）

- **现象**：暗部出现红绿蓝彩色斑点，甚至大片偏色（品红/青绿）。
- **机理**：Zero-DCE 的曲线**逐通道独立**、且暗区斜率最大 → 三个通道的噪声被各自放大 3.6~7.5×（实测色噪 std 0.39→2.93，7.5×）；近黑区没有可用色度信息，放大后变成"彩色大斑"。
- **证据**：`chroma_noise`（Cb/Cr 高频残差 std）：极端暗图 5.22→2.7（处理好时）；近黑分支未处理时 126 彩色块占比可达 14%。

### 问题 3：JPEG 8×8 块（次要，且只与编码格式相关）

- **现象**：低质量 JPEG 出现方格状边界。
- **机理**：JPEG 按 8×8 块做 DCT+量化，块边界不连续；4:2:0 还会把色度分辨率减半。
- **证据**：`blockiness` 实测：PNG ≈0.98~1.00、JPEG q95≈1.4、q70≈3.2、q40≈5+。
- **结论（重要）**：格式只是"帮凶"，实测同一张图 PNG/JPEG 增强后块效应差在噪声量级内；**PNG 只能去掉块与色度下采样，去不掉噪声放大**。

### 问题 4：处理后"发灰 / 暗部变暗 / 抹掉颗粒"

- **现象**：早期版本（E5/E8/E9）处理完图像发灰、暗部糊、或阴影比原版更暗（512 实测阴影区 −1.35 级）。
- **机理**：①在**输入**上做色度空间降噪会把色度信息抹平 → 8-bit 量化成大片同值 → 出现新分界线；②"混入平滑的中性抬亮"会替换掉暗区纹理；③亮度降噪去掉噪声的正向偏置后，曲线放大的平均值下降 → 暗部变暗。
- **证据**：色度噪声降 91% 的那版，彩色块占比 0.0011→0.1564、细节 std8 11.91→5.53（被判为不可接受，已写入 README 的"⚠ 更正"）。

### 问题 5：全局参数不适配（一张图一个设置）

- **现象**：同一组参数，极暗图要强处理、普通暗图一处理就丢颗粒、亮图根本不需要处理。
- **机理**：噪声强度、暗区占比、量化台阶数在不同图之间差 10 倍以上（输入色度噪声 0.10~1.13）。

## 第三部分 我们做了什么（按流水线顺序）

```
输入 sRGB
  │
  ├─① 分图判定 auto_decision
  │     ├ 均值 m < 5           → 近黑分支
  │     └ 否则按输入色度噪声 σc：<1.5 跳过；≥1.5 轻度色度处理
  │
  ├─② 去块 deblock（仅当 blockiness>1.03；只平滑"弱跨边界差<12"的 8×8 缝）
  │
  ├─③ 亮度降噪 luma_denoise（只在近黑分支用；NLM 作用 Y，按 strength 与原图混合）
  │
  ├─④ 暗部轻抬 prelift（仅均值<4；LAB 的 L 通道 gamma）
  │
  ├─⑤ DCE-Net 增强（8 次迭代，模型不改）
  │
  ├─⑥ 色度轻度平滑 chroma_light（只动 Cb/Cr；强度按 σc 分段：0.3~0.6→0.35σc，0.6~1.0→0.5σc，≥1.0→min(0.7,0.7σc)）
  │
  ├─⑦ 近黑限增益 limit_dark_gain（仅近黑分支；亮度<3 全用中性抬亮、3~12 线性羽化、>12 完全保留模型输出）
  │
  ├─⑧ 暗部补偿 shadow_lift（均值<15 时 Y 暗部抬 4 级，抵消"去噪导致变暗"）
  │
  
另外训练侧：
  └─⑩ 边缘损失 L_edge（论文式 (4.9)~(4.12)：逐通道 Sobel 幅值 L1，λ=0.22 ≈ 总损失 5%）
```

### 每个操作针对什么、效果如何

| 操作 | 针对问题 | 关键实现 | 实测效果 |
|---|---|---|---|
| ① 分图判定 | 问题 5 | 均值 + 输入色度噪声两个判据 | 132/512 等干净图**逐像素等于原版**（0.0% 变化） |
| ② 去块 | 问题 3 | 8×8 边界 4 抽头窄平滑，只在弱边界做 | 块效应比 1.004→0.967（eval15 −3.5%）；真边缘不碰 |
| ③ 亮度降噪 | 问题 1/4 | NLM 只作用 Y，按 strength 线性混合（避免 NLM 的 h 非线性悬崖） | 平坦区亮度噪声 −12.5%~−18.8% |
| ④ 暗部轻抬 | 问题 1 | 均值<4 才用，LAB-L gamma | 极暗图不整体发灰 |
| ⑥ 色度轻度平滑 | 问题 2 | 只动 Cb/Cr，分段强度 | eval15 色噪 **5.71→3.52（−38%）**；17 张极端图 2.93→2.25 |
| ⑦ 近黑限增益 | 问题 2 | 逐像素权重，只改亮度、色度拉中性 | 126 亮度 2.9→**21.5**、彩色块占比 14%→**0.2%** |
| ⑧ 暗部补偿 | 问题 4 | 均值<15 抬 4 级 | 512 阴影 −1.35 级 → **+0.01 级** |
| ⑩ 边缘损失（训练侧） | 结构/轮廓 | Sobel 幅值 L1，λ=0.22 | L_edge 41/41 张下降，平均 **−9.4%**；PSNR −0.81 dB、SSIM +0.0048 |

## 第四部分 综合效果（可写进论文的数字）

### A. 主客观指标（eval15，15 对，有正常光 GT）

| 指标 | 原版 Zero-DCE | 最终版 | 变化 |
|---|---|---|---|
| 色度噪声 `chroma_noise` | 5.71 | **3.52** | −38% |
| 平坦区亮度噪声 | 5.15 | **4.18** | −18.8% |
| 块效应比 `blockiness` | 1.002 | **0.967** | −3.5% |
| 人造边界 `artificial_edges` | 37.9 | **23.8** | −37% |
| PSNR vs GT | 15.86 | **15.97** | +0.11 dB |
| SSIM vs GT | 0.558 | **0.610** | +9.3% |
| 彩色块面积占比 | 0.54% | 1.23% | +（代价） |
| 饱和度 | — | −1.7% | （代价） |

### B. 极端暗图（17 张，均值 5~9 场景）

| 指标 | 原版 | 最终版 |
|---|---|---|
| 色度噪声 | 2.93 | **2.25（−23%）** |
| 细节 std8 | 8.40 | 8.29（基本不变） |
| 暗区条带 | 5.7 | **5.0** |
| 其中 7 张（132×2、512×4、101）| — | **与原版逐像素一致**（判定为"干净图，不处理"） |

### C. 下游友好度（Canny 边缘 vs GT）

| 指标 | 原版 | 最终版 |
|---|---|---|
| 边缘精度 precision | 0.690 | **0.810（+17.5%）** |
| 边缘召回 recall | 0.917 | 0.856（−6.6%） |
| 边缘像素数 | 29,615 | 22,970（−22%，说明假边缘被去掉） |

> 注意口径：这是"边缘是否落在 GT 轮廓附近"的代理指标，**不等于抓取成功率**（没有端到端实验，论文里不能这么写）。

### D. 边界（诚实的"做不到"）

1. 被 8-bit 量化 + 噪声彻底淹没的信息**无法恢复**；132 这类图（暗区仅 25 级、增益 5.8×）任何预处理都只能"少放大 / 打散台阶 / 不添新台阶"，不能让细节凭空出现。
2. 极暗 + 彩色区域仍有残余偏色（信息不足的物理边界）。
3. 采集端多帧平均（相机静止，噪声降 √N）是比任何后处理都有效的方案，但需要相机配合，本文未实现。

## 第五部分 可写的三条贡献

1. **量化了低照增强"马赛克"的成因**：8-bit 量化台阶 × 曲线暗区增益（实测 10~13×）是主因，JPEG 8×8 只是次要因素（有 PNG/JPEG 对照实验支撑）。
2. **提出一套"终端侧自适应预处理/后处理"流程**：按图判定 + 只动色度/近黑中性抬亮 + 暗部补偿，在不改模型结构的前提下，把 eval15 色噪降 38%、人造边界降 37%、SSIM 提升 9.3%、边缘精度提升 17.5%。
3. **给出可复现的量化体系**：10+ 个指标的公式、代码与阈值（`docs/指标定义与算法.md`），以及三次被自己证伪的中间方案（E5 大色块、E8 硬灰块、v4 引导羽化），可作为消融/负面结果写进论文。
