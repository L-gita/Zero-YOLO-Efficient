## 4. 4 处"会误导但不算造假"的写法（已处理）

1. **`MODELS["lol"]` 静默回退**：`--model lol` 缺权重时会回退到 `weights/sice_Epoch49.pth`，且原来无提示。
   → 已加 `warn_fallbacks()`（`enhance.py`）：启动即打印 `[warn] 训练目录权重缺失：… → 已回退到 weights/…`。
2. **批量脚本静默跳过失败图**：`batch_branch_compare.py` 原来只打印"缺少输出"且阶段末仍写"完成 N 张"。
   → 已加 `n_total / n_skipped / skipped_files`，打印 `完成 X 张（累计跳过 K）`。
3. **平坦掩码退化**：`eval_default_vs_base.py` 的 flat mask 若平坦像素<100 会退化为全图（口径变）。
   → `metrics_lib.flat_mask()` 返回 `degraded` 标记，`measure_all()` 输出 `flat_mask_degraded`；新工具 CSV 里可直接看到。
4. **`detail_std8` 两套定义**（3×3 邻域 std vs 8×8 分块 std）：
   → `metrics_lib` 同时提供 `detail_std3` 与 `detail_std8`，报告与 CSV 中标明用的是哪一个。
