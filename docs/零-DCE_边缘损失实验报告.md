> 核心代码（可直接对照你论文公式）：

```python
class SobelMag(nn.Module):
    """论文 (4.9)~(4.11)：逐通道 Sobel 梯度幅值 M = |Ix| + |Iy|"""
    def __init__(self, approx=True, normalize=False):
        super().__init__()
        kx = torch.tensor([[-1., 0., 1.], [-2., 0., 2.], [-1., 0., 1.]])   # (4.9)
        ky = torch.tensor([[-1., -2., -1.], [0., 0., 0.], [1., 2., 1.]])   # (4.9)
        if normalize:
            kx, ky = kx / 4.0, ky / 4.0
        self.register_buffer("kx", kx.view(1, 1, 3, 3).repeat(3, 1, 1, 1), persistent=False)
        self.register_buffer("ky", ky.view(1, 1, 3, 3).repeat(3, 1, 1, 1), persistent=False)
        self.approx = approx

    def forward(self, x):
        xp = F.pad(x, (1, 1, 1, 1), mode="replicate")        # 保持 N = H*W
        ix = F.conv2d(xp, self.kx, groups=3)                 # 逐通道，不混色
        iy = F.conv2d(xp, self.ky, groups=3)
        if self.approx:
            return ix.abs() + iy.abs()                       # (4.11)
        return torch.sqrt(ix * ix + iy * iy + 1e-12)         # (4.10)


class L_edge(nn.Module):
    """论文 (4.12)：L_edge = 1/(3N) Σ_c Σ_i |M(I_low)_i - M(I_enh)_i|"""
    def __init__(self, approx=True, normalize=False):
        super().__init__()
        self.sobel = SobelMag(approx=approx, normalize=normalize)

    def forward(self, enhanced, low):
        diff = (self.sobel(low) - self.sobel(enhanced)).abs()
        return diff.mean(dim=(1, 2, 3)).mean()               # 等价于 1/(3N)
```

| 项 | 基线 | +边缘损失 (4.12) |
|---|---|---|
| 权重 | `snapshots_sice/Epoch49.pth` | `snapshots_sice_edge/Epoch49.pth` |

## 4. 关键：这不是"靠变暗取巧"（亮度无关诊断）

图变暗 → 梯度幅值自然变小 → `L_edge` 也会变小。为排除这个混淆，另算 3 个**尺度无关**指标：

- `cos(g_low, g_enh)`：梯度**向量**余弦相似度（只看结构/方向，与亮度无关）
- `corr(M_low, M_enh)`：梯度**幅值图**的相关系数
- `L_edge_norm`：先**把增强图亮度缩放到与输入相同**，再算 (4.12)

| 数据集 | 模型 | cos ↑ | corr ↑ | `L_edge_norm` ↓ |
|---|---|---|---|---|
| eval15 | 低照 vs GT（参考上限） | 0.7683 | 0.7646 | 0.1628 |
| eval15 | 基线 | 0.6309 | 0.6286 | 0.0351 |
| eval15 | **+边缘损失** | **0.6421** | **0.6469** | **0.0342** |
| LIME | 基线 | 0.6983 | 0.6402 | 0.1001 |
| LIME | **+边缘损失** | **0.7175** | **0.6683** | **0.0969** |
| DICM | 基线 | 0.7170 | 0.6381 | 0.1409 |
| DICM | **+边缘损失** | **0.7502** | **0.6854** | **0.1331** |

**读法**：三个指标同向改善（cos +0.011~+0.047、corr +0.018~+0.047、`L_edge_norm` −2.6%~−5.6%）。也就是说，即使把亮度因素剔除，**加边缘损失的模型，其梯度场确实更接近低照输入** —— 这正是公式 (4.12) 要优化的东西，不是变暗造成的假象。

## 6. 为什么会出现"变暗 + PSNR 略降"（理论解释）

LE 曲线 `x + α(x² − x)` 在暗区的斜率是 `1 + |α| > 1`，所以**提亮本身就会放大梯度**；而 (4.12) 是**双向 L1**（`|M_low − M_enh|`，既罚"变弱"也罚"变强"），于是它天然和"把暗区提亮（放大对比度）"这个目标对着干：

- λ 越大 → 越偏向"梯度不要放大" → 图越暗、越平（本实验 λ=0.22 已经能看到这个倾向）
- λ=0 或很小的 λ → 边缘场影响可忽略，退化为原版

另外它和原有的 `L_spa`（邻域差分保持）在目标上有部分重叠，两者叠加会共同抑制局部对比度变化，这也解释了"变暗幅度比预期大"。

## 7. 建议（下一步可选项）

| 方案 | 做法 | 预期 |
|---|---|---|
| A. 降 λ | `--edge_weight 0.05~0.10` 重训 50 轮（约 25 min） | 保留"边缘更贴输入"的效应，亮度和 PSNR 损失变小 |
| B. 单边 hinge | 把 4.12 的 `abs(...)` 换成 `F.relu(M_low - M_enh)`，只罚"边缘变弱" | 允许提亮放大对比度、只阻止边缘被抹平 —— 更贴近"保护边缘"的初衷（≈ +15 行） |
| C. 精确幅值 | 加 `--edge_exact`（用 4.10 的 √ 而不是 4.11 的 L1 近似） | 与论文 (4.10) 完全一致，开销略大、对 λ 标定影响很小 |
| D. 视觉/下游验证 | 在检测/抓取模型上比 mAP 或用边缘保持指标（如 BDE） | 论文讲的是"便于机器人抓取"，最终该用下游任务证明收益 |

**本报告只做了 A 的标定与 λ=0.22 的实验；B/C/D 都还没跑**（B 需要改 Myloss.py 再加一个开关，C 只需加参数）。
