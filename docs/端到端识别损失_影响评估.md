# 加"识别损失"做端到端训练：对现有工作的影响评估

> 结论先说：**影响可控，属于“训练侧新增一支”，现有推理侧成果（预处理判据 / 后处理 / 三入口 / 权重）不需要推翻**。
> 代价主要在**标注一份带框的小数据集**和**训练/评测变重**，不在代码结构。

## 1 为什么影响小

| 现有工作 | 是否受影响 | 原因 |
|---|---|---|
| DCE-Net 结构（`model.py`） | 不改 | 端到端训练只换损失，不动网络结构 |
| 现有推理管线（`enhance.py` + `scripts/preprocess.py`） | 不改 | 推理侧预处理/后处理与训练损失解耦，继续作为“最终版”和基线 |
| 四个权重（`weights/*.pth`） | 保留 | 作为基线权重；新训练产出新权重并列，不覆盖 |
| 训练脚本 | 小改 | `lowlight_train.py` 已有损失插口（`--edge_weight` 先例，第 73 行组合各项损失），加 `--rec_weight` 属同类改动 |
| 评测脚本 | 需扩 | 现有 PSNR/SSIM/色噪/细节/伪边缘/边缘 P&R 都复用，**另需检测指标**（召回/精确率/置信度，已用 YOLOv8n 代理跑通） |
| 文档与论文结构 | 需重组 | 现有=贡献1（推理侧）；新增=贡献2（训练侧），消融表要重跑 |

## 2 需要新增的代码

1. `Myloss.py` 新增一个类（例如 `L_det`）：
   - 最简版：冻结检测器的**特征图对齐/蒸馏**损失（不需要框，最容易落地）；
   - 完整版：冻结检测器输出的 **pre-NMS 分类+框回归损失**（需要 GT 框）。
2. `lowlight_train.py`：新增 `--rec_weight` 与 `--rec_mode {feat,det}`，在 `loss = ...` 后按需加权（与现有 `--edge_weight` 同样写法）。
3. 一个“冻结检测器”封装：`ultralytics` 已装（8.4.220），加载 `weights/yolov8n.pt`，`requires_grad_(False)`、`eval()`。
4. 评测脚本加检测指标（`%TEMP%` 里的 YOLO 代理脚本可直接固化为 `scripts/eval_yolo.py`）。

## 3 三个真实难点（按风险排序）

1. **没有 GT 框**（最大隐藏成本）：LOL/SICE 只有低照/正常光配对，无检测标注。
   解法：用**正常光 GT 图**跑 YOLO 自动标注 + 人工抽检 20%；50~100 张即可做消融。预计 0.5~1 天。
2. **NMS 不可微**：检测损失要取 NMS 之前的分支（YOLOv8 的 `preds` 原始输出），只对分类/框回归项反传，不要梯度穿过 NMS。
3. **显存与时间**：4060 Laptop 8 GB，双网络反向会吃紧。建议 256×256、batch 8→4、开 `cudnn.benchmark`；
   单轮从 ~28 s 增到 ~60~90 s，50 轮约 1~1.5 h/次（可接受，但要跑多组消融）。

## 4 建议的分阶段路线

| 阶段 | 做什么 | 成本 | 风险 |
|---|---|---|---|
| P0（已完成） | 训练侧 `L_edge`（论文 (4.9)~(4.12) Sobel 边缘损失），已有 `--edge_weight` | 已完成 | 低 |
| **P1（推荐先做）** | 冻结 YOLO 的**特征蒸馏损失**（增强图特征 ≈ 正常光图特征） | 代码 1 天 + 训练/评测 0.5 天 | 低（不需要框） |
| P2 | 冻结 YOLO 的 **pre-NMS cls+box 损失**（需 GT 框） | +1~2 天（含标注） | 中（域差/伪标注噪声） |
| P3 | 真端到端（微调检测器 + 增强网络交替） | 再加 2~3 天 | 高（不稳定、易崩） |

## 5 评测与论文口径

- 消融行：`baseline(Zero-DCE)` / `+推理侧预处理(当前最终版)` / `+L_edge` / `+L_rec` / `+两者`；
- 指标：检测（召回/精确率/平均置信，以正常光 GT 检测为参照）+ 现有质量指标（色噪、细节 std8、伪边缘、PSNR/SSIM）；
- 诚实边界：检测代理在 15 张图上有噪声（V0 vs V2 互有胜负），**必须扩到 100+ 张才能讲“提升”**；
- 论文结构：贡献1 = 推理侧两分支预处理（已完成、有量化）；贡献2 = 识别驱动训练（新增）。

## 6 对“最终版”的处置

- 现有最终版**冻结**为 `v1.0-final`（git tag + 离线 zip 快照），作为基线与推理包装；
- 端到端训练只产出新权重，通过 `enhance.py -m <新ckpt>` 并列对比，不改现有入口默认行为。
