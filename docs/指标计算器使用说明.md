# 指标计算器 使用说明

## 1. 它是干什么的

输入一张（或一批）图像 → 自动做两件事：

1. 计算**输入图**的各项指标；
2. 调用**最终版（去马赛克）增强**（与 `3_去马赛克最终版.bat` 完全同一份代码）→ 计算**增强后**的指标。

可选择性加上"原版 Zero-DCE（`-m sice`）"作对照（`--with-base`），有正常光参考图时算 PSNR/SSIM/边缘 P/R（`--gt`）。

## 2. 三种用法

```bat
:: ① 双击（会弹选图框，可多选）
指标计算器.bat

:: ② 拖拽：把图片或文件夹拖到 bat 上
:: ③ 命令行
python scripts\image_metrics.py 图片1.jpg 图片2.png -o 输出目录 --with-base
python scripts\image_metrics.py 某个文件夹 --with-base          :: 递归处理
python scripts\image_metrics.py 低照.png --gt 正常光.png --with-base   :: 有参考图
python scripts\image_metrics.py --self-test                       :: 指标自检（24 项）
```

输出目录默认是**第一张图同级的 `指标结果\`**，包含：

| 文件 | 内容 |
|---|---|
| `metrics.csv` | 每张图三组（输入 / 最终版 / 可选原版基线）的全部指标数值 |
| `report.md` | 指标定义表 + 逐图表格 + `enhance.py` 真实判定日志 + 失败清单 |
| `figures/<名>_compare.png` | 输入 / 原版 / 最终版 三联对比图（可用 `--no-fig` 关闭） |

## 3. 指标口径（与报告/论文一致）

| 指标 | 含义 | 越大越好？ |
|---|---|---|
| 亮度 | 灰度均值（0~255） | 看场景 |
| 对比度 / 饱和度 | 灰度 std / HSV 的 S 均值 | — |
| 色度噪声 | Cb/Cr 减高斯(σ1.5) 高频残差 std | **越小越干净** |
| 平坦亮度噪声 | 同上，只统计输入平坦区（Sobel<20） | 越小越好 |
| 细节 std8 | 8×8 分块内 std 均值（含噪声成分） | 不是越高越好，需结合噪声看 |
| 暗区条带 / 级数 | 暗区大面积灰度级最大间隔 / 级数 | 条带越小越好、级数越多越细腻 |
| 伪边缘 | 色度跳变≥dc 且亮度跳变<dy 的边界数/千像素 | 越小越好（假边少） |
| 块效应比 | 8 列边界 |Δ| ÷ 非边界 |Δ|，1.0=无块 | 越接近 1 越好 |
| 彩色大块占比 | 色度幅值>阈值的最大连通域面积占比 | 越小越好 |
| 结构 cos | 与输入梯度方向余弦 | 越接近 1 越好 |
| PSNR / SSIM / 边缘 P·R | 与参考图（GT）比较 | 越高越好 |

注意：
- **PP/SSIM 需要参考图**（`--gt`），没给就不算，不会编造；
- `flat_mask_degraded=1` 表示该图平坦像素太少、掩码退化为全图（口径变化，报告里会标）；
- `detail_std8` 是"纹理+噪声"的混合量，压噪必然下降，不能单独当"纹理损失"。

## 4. 为什么这些数可信

1. 增强图不是"另算一套"：直接调用 `enhance.py` 子进程，与 bat 输出同一份代码、同一份权重；
2. 指标由 `scripts/metrics_lib.py` 纯函数计算，全部是像素级卷积/直方图/连通域统计，无常量；
3. 自带解析自检：`--self-test` 用**已知答案的合成图**（黑/白/纯色/渐变/棋盘/随机）验证每个指标，24 项全 PASS 才继续；
4. 失败会**显式报错**：读图失败/增强失败会记入失败清单并让退出码=1，不会静默"通过"。
