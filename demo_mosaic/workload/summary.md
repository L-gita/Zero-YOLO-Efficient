# 原版基线 vs 去马赛克最终版（两种工作点）

- **base**：原版 Zero-DCE（无任何预处理）
- **default**：去马赛克最终版默认（s=0.20 + 不碰色度 + 阴影补偿）
- **clean**：干净档（s=0.45 + 局部色度平滑 + 阴影补偿）

指标：亮度(0-255)、色噪(色度高频残差)、细节(3×3 局部 std8)、人造边界(每千像素)、梯度方向 cos、PSNR/SSIM（仅 eval15 有 GT）
