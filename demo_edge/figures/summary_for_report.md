## 一、每个指标说明什么

| 指标 | 含义 | 期望方向 | 本次实测（基线→边缘） |
|---|---|---|---|
| PSNR (dB) | 与正常光 GT 的像素级误差 | 越高越好 | 17.22 → 16.41（−0.81） |
| SSIM | 与 GT 的结构相似度 | 越高越好 | 0.5509 → 0.5557（+0.0048） |
| L_edge (4.12) | 增强前后梯度幅值之差（论文定义的损失本体） | 越低越好 | 0.2900 → 0.2627（−9.4%） |
| cos(g_low,g_enh) | 梯度向量方向一致性（尺度无关） | 越高越好 | 0.6309 → 0.6421 |
| corr(M_low,M_enh) | 梯度幅值图相关（尺度无关） | 越高越好 | 0.6286 → 0.6469 |
| 亮度归一 L_edge | 把增强图缩放到输入亮度后再算 4.12，排除“变暗取巧” | 越低越好 | 0.0351 → 0.0342 |
| M 放大倍数(eval15) | M(输出)/M(输入)，衡量梯度被放大几倍 | 越接近 GT 的 3.75× 越自然 | 6.14× → 5.64× |

## 三、报告里怎么讲（建议口径）

1. **先说机制**：Zero-DCE 的 LE 曲线在暗区斜率 1+|α|>1，提亮必然放大梯度；无约束时网络会把噪声也一起放大。论文 (4.12) 用逐通道 Sobel 幅值差把这件事约束住。
2. **再说效果**：41/41 张图梯度场更贴近输入（L_edge 平均 −9.4），且排除亮度干扰后仍成立。
3. **再说代价**：亮度 −10.4%、PSNR −0.81 dB、SSIM +0.0048 —— 它是正则项而非锐化项。
4. **落到建议**：若要兼顾亮度，λ 调到 0.05~0.10（对应边缘项占 1%~2.5%），或改用单边 hinge。
